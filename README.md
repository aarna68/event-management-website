# Eventora — Event Management Website

A modern, responsive event management website built for the K Explore Web Designing task.

## Features
- Responsive HTML5/CSS3/JavaScript website
- Attractive hero section and event cards
- Event search and category filtering
- Detailed event modal
- Registration form with JavaScript validation
- Registration confirmation message
- Local Storage registration management
- Dark/light mode
- Smooth scrolling and hover animations
- Mobile navigation
- Accessible labels and semantic HTML

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts
- Git & GitHub

## Run Locally
Open `index.html` directly in a browser, or use VS Code Live Server.

## Deploy
The project is static and can be deployed using GitHub Pages, Netlify, or Vercel.

### GitHub Pages
1. Create a GitHub repository.
2. Upload all project files.
3. Go to Settings → Pages.
4. Select the `main` branch and `/ (root)`.
5. Save and open the generated Pages URL.
